# Purpose and scope

This tool allows users to define and edit BOM structures before they are created in the target PLM system.

The tool does not create objects in PLM directly, but prepares validated definitions for creation.


# Functional requirements

## BOM managenent

-Define and edit bom lines(add,delete,move)
-move bom lines in hierarchy
-define inheritance and conditions in natural language




Logging

- Change date / time
- User who made the change
